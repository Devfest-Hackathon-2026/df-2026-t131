# 富山市のオープンデータの公開状況（調査）

作成：メンバー4　／　11/6　／　調べ方：富山市オープンデータカタログ（https://opdt.city.toyama.lg.jp/ 、CKAN）の検索 API で「文化財」「観光」「イベント」を検索
目的：今後ほかの地域に広げるとき・ランドマークを増やすときの材料（docs/design.md 8章・15章）

- 3種類とも富山市のカタログにある。組織は富山市、更新は「不定期」
- **どれも最終更新が 2020〜2021 年で古い**。今の情報として使うなら、公式ページで確かめ直す必要がある
- 形式は CSV ではなく XLSX。「自治体標準オープンデータセット」の形に沿っているかは、標準の仕様書と比べていないので未確認

## 1件ごと

### 文化財情報（infomap-toyama12）

- 中身：国指定・国登録、県指定、市指定の文化財のうち、富山市が持っている・管理しているものの一覧
- 項目：ID、レイヤ名称、分類名称、名称、所在地、番号、種別、時代、詳細情報、所有者、指定年月日、OPENFLG、緯度、経度
- 使っている所：lm_0008 富山城址公園の出典

### 観光施設情報（infomap-toyama10）

- 中身：観光施設（ほかに同じデータセットに「富岩水上ライン」の運航と乗船場の情報）
- 項目：ID、レイヤ名称、分類名称、施設名、所在地、TEL、FAX、URL、備考、OPENFLG、緯度、経度

### イベント情報（infomap-toyama11）

- 中身：令和2年度の観光イベント・祭りの一覧
- 項目：ID、レイヤ名称、分類名称、開催時期、イベント・祭りの名称、開催場所、URL、OPENFLG、緯度、経度
- 注意：令和2年度のもので、日付ではなく「開催時期」。今のアプリのイベント（`schema/event.schema.json`、開始・終了の時刻と開催状態）にはそのまま入らない。デモは手作りのモック（`cloud/data/manual/events.json`）を使う

## 使うときの注意

- CC BY なので、使うときは出典（富山市）を表示する（`docs/attribution.md` に書く）
- 古いデータなので、原稿に使う事実は公式のページで確かめ直す
- 位置は OpenStreetMap で確かめた座標で登録する決まり（オープンデータの緯度・経度は確認用に使う）
